# Palimpsest（重写之卷）· 在线试玩

**▶ 开始游戏：** https://yukijiang419.github.io/palimpsest-play/

这里放的是 Palimpsest 的 WebGL 打包版本，通过 GitHub Pages 发布。源码、设计说明和个人贡献见 **[yukijiang419/palimpsest](https://github.com/yukijiang419/palimpsest)**。

- 建议使用桌面版 Chrome 或 Edge，首次加载约 95 MB
- 演示视频：[YouTube](https://youtu.be/ODcsN_qIRAg)

| 操作 | 按键 |
| --- | --- |
| 移动 | WASD |
| 闪避 / 冲刺 | 左 Shift |
| 攻击 | 鼠标左键 |
| 冲刺斩 / 审判斩 | F / Q |
| 路径交互 | 按住鼠标右键 |
| 锁定目标 | 鼠标中键 |
| 切换武器 | 1 / 2 |
| 交互 | E |
| 武器属性 | O |
| 谜题：切换时间线 / 推拉方块 / 重置 | T、R / 按住 F / X |
| 地图 | M |
| 菜单 | Esc |
